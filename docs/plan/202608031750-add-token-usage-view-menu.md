# Token 用量页改为三视图菜单

## Summary

- 在主导航下增加顶部吸附的页内菜单：`今日 / 总计 / 用量分析`，每次只展示一个视图。
- 默认进入“今日”，菜单承担区块标题，移除现有三个外层标题及重复留白。
- 保留三个视图现有内容与数据口径，不修改后端或数据库。

## Implementation Changes

- 新增内部 `UsageView = today | total | analysis`，使用 `view` 查询参数保存当前视图；菜单切换写入浏览器历史，支持刷新、前进后退和分享链接。
- 无 `view` 时默认并规范化为 `view=today`；旧链接若包含 `period` 或 `tool`，自动进入 `view=analysis`；无效 `view` 回退到今日。
- 切换视图时保留分析区的 `period/tool` 参数；修改时间或工具筛选时保留 `view=analysis`，避免现有筛选逻辑覆盖菜单状态。
- 三个视图仅在首次打开时请求数据，结果保留在现有状态中，返回该视图时直接复用；重试仍只影响对应视图，页面 `aria-busy` 只反映当前视图。
- 菜单使用语义化页内导航与三等分链接，每项显示英文眉题和中文名称；活动项使用现有青色强调，保持至少 44px 触控区域、键盘焦点和 `aria-current`。
- 菜单采用半透明深色背景、轻量模糊和顶部吸附；内容区取消互相分隔的大段边距，今日卡片、全部历史卡片和分析筛选面板直接承接菜单。
- 页面保留一个无障碍主标题 `Token 用量`；活动内容通过菜单项关联，不再同时渲染隐藏的其他区块。

## Test Plan

- 检查默认访问、三个合法 `view`、无效 `view` 及旧 `period/tool` 链接的规范化结果。
- 检查菜单切换、刷新、浏览器前进后退，以及分析筛选后切走再返回时状态保持正确。
- 确认每个接口仅在对应视图首次打开或主动重试时请求，未打开视图不产生请求。
- 覆盖三个视图各自的加载、空数据、错误与重试状态，确认错误不会影响其他视图。
- 用户在 320–420px 和桌面宽度下检查吸附菜单、44px 触控区域、长分析页切换及无横向溢出。
- Agent 仅执行源码检查和 `git diff --check`；不运行前端构建、类型检查、lint、测试或开发服务器。

## Assumptions

- 菜单默认顺序固定为 `今日 / 总计 / 用量分析`。
- 切换视图不自动刷新已加载数据，也不增加轮询。
- 不改变今日、全部历史、分析区内部卡片、图表、工具颜色和 Token 统计口径。
