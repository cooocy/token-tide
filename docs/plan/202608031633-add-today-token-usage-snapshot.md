# Token 用量页增加今日用量速览

## Summary

- 在页面导航下方、现有 `ALL-TIME / 总计` 之前增加 `TODAY / 今日用量` 速览。
- 突出今日 Token 总量，并通过四色贡献条展示 Claude、Codex、OpenCode、Pi 的用量占比。
- 速览固定展示浏览器本地“今天”的全部工具数据，不受下方时间、工具筛选影响，也不提供点击联动。

## Implementation Changes

- 复用现有 `/token-usage/summary` 和本地时区区间计算，新增独立的今日汇总请求、加载、错误、重试及竞态保护状态；不修改后端、API 类型或数据库。
- 今日卡片左侧展示紧凑总量、精确 Token 数和请求数；右侧展示贡献条及四个工具的紧凑 Token 数和百分比。四个工具始终出现，零用量显示 `0` 和 `0%`。
- 贡献条复用既有工具配色；无数据时保留中性轨道，不显示误导性的占比色块。完整数值和贡献关系通过 `title`、`aria-label` 或隐藏描述提供。
- 桌面端采用“总量 / 工具贡献”双栏，移动端纵向排列；沿用页面 `20px` 卡片圆角、字体和色彩体系。新的分段贡献条作为该速览唯一的视觉重点，不重复使用现有圆环图。
- 将页面主标题语义移到“今日用量”，现有 `ALL-TIME / 总计` 保持原文和原有内容，调整为后续二级区块；下方分析区及 URL 筛选行为保持不变。

## Test Plan

- 静态检查今日边界使用浏览器本地零点到当前时间，且始终以全部工具查询。
- 覆盖正常数据、单工具占满、极小占比、四工具均为零、加载失败与重试场景。
- 确认修改下方 `今天 / 7 天 / 30 天` 和工具筛选不会改变顶部速览。
- 用户在桌面及 320–420px 手机宽度下检查总量、贡献条、四个工具数值均清晰且页面无横向溢出。
- Agent 仅执行源码检查和 `git diff --check`；不运行构建、TypeScript、lint、测试或开发服务器。

## Assumptions

- “今日”沿用现有口径：浏览器本地时区的当天零点至请求时刻。
- 工具贡献同时展示 Token 数和占今日总量的百分比，不增加模型、Token 类型等明细。
- 速览在页面加载时读取，不增加轮询或自动刷新机制。
