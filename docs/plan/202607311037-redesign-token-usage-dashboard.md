# 重设计 Token 用量看板

## Summary

- 首屏固定展示全部历史累计用量，以及“按工具”“按模型”两个环形饼图；不受下方筛选影响。
- 下方作为独立分析区，仅保留“今天 / 7 天 / 30 天”和工具筛选，并完整保留 Token 分布、每日用量、模型排行。
- 延续 TokenTide 深海色系与现有字体，使用一组类似声呐读数的双环图作为页面视觉记忆点，不引入图表依赖。

## Implementation Changes

- 新增公开只读接口 `GET /token-usage/overview`，返回全部历史的 `totals`、`tools` 和 `models`；统计使用数据库聚合，不把事件加载进 Python。
- 保留现有 `/totals` 和 `/summary` 兼容性，不修改数据库结构或迁移。
- 前端新增可复用、无依赖的 SVG 环形饼图组件；工具图使用稳定的工具配色，模型图展示 Token 最高的 5 个模型并将其余合并为“其他”。
- 首屏排成连续的概览仪表盘：累计 Token 和请求次数为主读数，两个分布图为并列读数；桌面并排，窄屏改为纵向布局。
- 下方增加“用量分析”区，将时间、工具筛选放在区标题之后；筛选仅重新请求 `/summary`。
- 保留并重排 Token 分布、每日用量和模型排行；将 `MODEL DEPTH` 改为 `MODEL USAGE`。
- 移除“总计”筛选及对应前端分支；旧的 `?period=total` 按最近 7 天处理，工具参数继续保留。
- 概览与筛选分析使用独立加载、错误和重试状态，并同步更新 README。

## Visual Direction

- 继续使用 `#071820` 深海背景、`#0A222B` 面板、`#E7F5F4` 主文字和 `#32D6C5` 主强调色，并用 `#DCA36A`、`#899CFF` 区分数据系列。
- 保留 Avenir Next 展示字体、系统中文字体和 SF Mono 数据字体，不引入网络字体。
- 控制卡片数量与装饰，重点强化双环图、数值对齐、留白和筛选区层级；保持 44px 触控区域、键盘焦点和 reduced-motion 支持。

## Test Plan

- 后端测试覆盖空库、三个工具补零、多工具多模型聚合、模型排序、请求次数和 Token 字段准确性，以及新增公开路由。
- 静态检查首屏概览不随筛选变化，今天/7 天/30 天和工具参数仍正确生成 summary 请求。
- 检查零数据、单分段、超过 5 个模型、超长模型名、极大 Token 数、概览失败和分析失败状态。
- 检查 320px、常见手机宽度和桌面布局，以及饼图的可访问文本、键盘焦点和颜色图例。
- 实施阶段仅执行静态搜索与 `git diff --check`；Python 测试、前端构建、类型检查和运行验证由用户执行。

## Assumptions

- “总用量”指全部历史累计值，两个饼图也采用相同的全部历史口径。
- 饼图按 `total_tokens` 计算比例；`total_tokens` 不由其他 Token 字段相加推导。
- 不新增缓存、汇总表、迁移、第三方图表库或新的时间范围。
