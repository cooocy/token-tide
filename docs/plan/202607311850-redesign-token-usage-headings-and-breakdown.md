# 重构 Token 用量页面标题与区间分布

## Summary

- 重新梳理页面从全历史总计到筛选区间分析的标题层级。
- 将下方两行 Token 表格改为与上方累计卡片同构的“主读数 + 明细”布局。

## Implementation Changes

- 页面顶部标题由 `ALL-TIME OVERVIEW / Token 用量` 改为两行 `ALL-TIME / 总计`。
- 全历史累计卡片标题由 `TOTAL TOKENS / 累计总用量` 改为 `TOKEN BREAKDOWN / Tokens 分布`。
- 下方筛选区间卡片使用 `PERIOD BREAKDOWN / 区间分布`，避免与全历史数据混淆。
- 下方卡片左侧突出筛选区间总 Token，附精确值和请求次数；右侧展示输入、输出、缓存写入、缓存读取和推理。
- 上下卡片共享数值、明细层级及响应式规则；移除原两行表格和“用量分析”标题旁重复的请求次数。
- 宽屏采用左右布局，窄屏保持紧凑排列，极窄屏改为上下布局。

## Interfaces and Behavior

- 不修改 API、类型或数据库结构；下方数据继续来自当前筛选对应的 `summary.totals`。
- `total_tokens` 保持独立统计，不根据五项明细求和。
- 筛选、加载、错误重试和零数据提示行为保持不变。

## Verification

- 静态核对所有中英文标题及大小写，特别是用户指定的 `Tokens 分布`。
- 检查不同时间、工具筛选后，区间总量、请求次数及五项明细同步更新。
- 检查零数据、超大数值、无障碍标签，以及 320px、常见手机宽度和桌面布局。
- 执行 `git diff --check`；不运行前端构建、类型检查、lint 或开发服务器。
