# 重构 Token 用量年度日历

## Summary

- 一级视图顺序调整为 `今日 → 日历 → 总计 → 用量分析`，URL 保持兼容。
- 保留独立日历视图，改为自然年日历和 GitHub 风格年份选择。
- 固定强度边界为 `250W / 2000W / 4000W`，色板改为 `#102B33 / #16434B / #176A6B / #1EA59A / #5BE6CF`。
- 删除日历上方日期总量；点击日期后在下方展示完整的 Token 分布、按工具、模型用量三卡。

## Implementation Changes

- 年度日历与导航：
  - 导航固定按今日、日历、总计、用量分析排列。
  - 当前年默认选中今天；历史年默认选中最后一个活跃日，无数据时选中 12 月 31 日。
  - 桌面年份按钮位于日历右侧，移动端为上方横向滚动按钮。
  - 日历按周一对齐连续展示 53 周；当前年份以今天为终点，历史年份以该年 12 月 31 日为终点。
  - 53 周窗口跨年加载真实数据，元旦后继续承接上一年；终点之后不生成可滚动区域。
  - `view=calendar&year=YYYY` 保存年份，非法年份回退有效范围。
- 日期明细：
  - 日历下方显示 `DAY DETAILS / 日期明细`、选中日期和强度档位。
  - 复用现有三卡组件；单日明细请求与日历请求分别维护加载、错误、重试和数据键。
  - 点击或键盘移动才选择日期，悬停不触发请求；移动端定位到选中日期所在周。
- 后端接口：
  - `TokenUsageCalendar` 增加 `available_years`，从最早数据年份到当前年份倒序生成；无数据仅返回当前年。
  - `/token-usage/summary` 增加可选 IANA `timezone`，复用现有 `calendar_timezone` 保证历史日期和 DST 日界线正确。
  - 不增加路由、迁移、缓存或汇总表。

## Test Plan

- 后端覆盖年份范围、无数据、时区、DST、非法时区、旧请求兼容和自然年范围。
- 前端验收导航顺序、固定边界临界值、年份深链接、连续 53 周跨年衔接和当前年右侧滚动边界。
- 验收日期快速切换、空日期三卡、桌面年份栏、320px 移动端滚动、键盘与 reduced-motion。
- 不运行 Python、前端构建、类型检查或测试命令；仅做静态检查与 `git diff --check`。

## Assumptions

- 日历与日期明细统计所有工具，不增加工具筛选。
- 年份列表连续展示最早数据年份到当前年份，包括中间无数据年份。
- 今日三卡保持不变，分析筛选不影响日历。
- 不提交或推送，除非用户另行要求。
