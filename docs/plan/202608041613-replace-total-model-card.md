# 统一今日与总计的模型用量卡片

## Summary

- 「今日」当前已经复用「用量分析」的 `MODEL USAGE / 模型用量` 卡片，无需重复修改。
- 将「总计」的 `MODEL SHARE / 按模型` 环形图替换为同一个模型用量组件，使三个视图的模型展示完全一致。

## Implementation Changes

- 「总计」向 `ModelUsagePanel` 传入全部历史的 `overview.models` 与 `overview.totals.total_tokens`。
- 删除仅供总计模型环形图使用的派生数据、非零模型计数，以及不再使用的模型分布与颜色计算代码。
- 保留模型列表现有行为：完整模型列表、Token 数、相对用量条、请求次数、总量占比、长名称截断、空状态和桌面滚动。
- 保持「Tokens 分布」「按工具」「模型用量」共用一个外层卡片；桌面三列、移动端纵向排列。
- 不改后端、API、数据口径、排序、路由、加载及重试逻辑。

## Interfaces

- 不新增或修改公共 API、响应类型或 URL。
- 仅调整页面内部渲染，并清理失去调用方的内部辅助逻辑。

## Test Plan

- 静态确认「今日」和「总计」均显示 `MODEL USAGE / 模型用量`，不再出现模型环形图或「按模型」。
- 检查「总计」模型 Token、请求次数和占比均使用全部历史数据。
- 覆盖无模型、单模型、多模型、长模型名和大 Token 数。
- 检查桌面三列、320–420px 移动端纵向布局及外层圆角/内部边框一致性。
- 仅执行源码检查、失效引用搜索和 `git diff --check`；构建、类型检查、Lint 与运行验证由用户执行。

## Assumptions

- 「改成用量分析里的模型用量」表示直接复用现有 `ModelUsagePanel`，不另外设计颜色、Top 5 聚合或独立变体。
- 「今日」现有实现已满足目标，本次实际代码改动集中在「总计」及相关死代码清理。
