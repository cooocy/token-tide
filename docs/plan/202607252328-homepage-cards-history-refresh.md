# 主页卡片满宽与 History 顶部刷新按钮

## Summary

- 主页移除卡片左侧圆点及其预留空间，让平台卡片和加载骨架撑满内容宽度。
- History 页移除底部吸附刷新栏，将刷新按钮放到余额概览区域右上方，与主页刷新按钮保持一致。

## Implementation Changes

- 主页删除 `tide-node` 元素、状态样式和脉冲动画；移除 `.provider-stack` 的左侧内边距。卡片内部状态圆点继续保留。
- History 页在 `AVAILABLE BALANCE` 标题行右侧放置紧凑刷新按钮，复用主页的按钮外观、禁用状态和旋转动画，文字使用“刷新”或“刷新中”。
- 删除 History 页底部 `action-dock`，并清理已经没有调用方的 `.action-dock`、`.primary-action` 及桌面端网格适配样式。
- 保持刷新接口、提示消息、余额和历史数据加载逻辑不变。

## Test Plan

- 主页正常、加载、失败和更新中状态下，卡片或骨架均占满可用宽度，左侧不再出现圆点或空白槽。
- History 页刷新按钮位于顶部余额区域；刷新时禁用并旋转，完成后提示和数据更新行为不变。
- 手机和宽屏布局下均不再出现底部吸附区域，图表与记录双栏布局不受影响。
- 仅执行静态差异与 `git diff --check`；按项目约定，构建、类型检查和页面运行由用户完成。

## Assumptions

- “参考主页”指复用主页当前的紧凑描边刷新按钮，而不是把按钮放进最上方返回导航栏。
- 本次只调整布局和视觉元素，不修改 API、数据类型或刷新语义。
