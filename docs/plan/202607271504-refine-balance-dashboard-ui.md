# TokenTide 首页与历史页 UI 精调

## Summary

调整首页标题、卡片更新时间布局和历史页重复文案。

## Implementation Changes

- 首页主标题由“平台余额”改为“余额看板”，同步相关无障碍文案；字号从 `clamp(2.5rem, 13vw, 4.5rem)` 调整为 `clamp(2.2rem, 11vw, 3.8rem)`。
- 更新时间保留中文并删除“更新”后缀：不足 1 分钟显示“刚刚”，随后依次显示“n 分钟前”“n 小时前”“n 天前”，7 天及以上保留绝对时间。
- 将更新时间及相邻异常状态从卡片右侧移到平台名称下方并左对齐，使名称和元信息组成的文本列与 38px logo 框垂直居中；右侧仅保留“余额趋势”入口。
- 历史页删除净变化数字和“本段变化”标签，将本段补给与本段消耗改为余额右侧的两行紧凑数字：上方显示 `+补给金额`，下方显示 `-消耗金额`；不再单独占用一行汇总卡片。
- 图表区英文标题由 `TIDE TRACE` 改为 `BALANCE TRACE`，中文“余额潮位”保持不变。
- 不修改后端 API、数据结构、余额计算或历史事件逻辑。

## Verification

- 静态检查“刚刚、3 分钟前、4 小时前、5 天前、绝对时间”等显示。
- 检查成功、更新中、失败、从未更新及平台不可用状态，确保异常信息仍与更新时间相邻。
- 检查窄屏、长平台名和多币种场景，确保 logo、名称、时间、金额及“余额趋势”不溢出。
- 确认历史页不再显示净变化数字和“本段变化”，余额右侧依次显示补给和消耗金额，原独立汇总行已移除。
- 遵循仓库约定，仅做 diff 和静态检查；构建、类型检查及页面运行由用户执行。

## Assumptions

- 余额右侧展示本段补给和本段消耗的带符号金额，不显示文字标签；无消耗时继续显示中性的 `0`。
- 继续沿用当前 7 天后切换绝对时间的规则。
- 缺失或无效时间的提示文案保持不变。
