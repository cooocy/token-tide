# 统一 GitHub Profile SVG 三栏布局

## Summary

- 移除左栏独立底色，让三栏统一使用卡片全局背景，仅保留竖向分隔。
- 删除中栏 `Tokens by local day` 和右栏 `Share of Tokens`。
- 保留现有 `720×220` 尺寸、三栏宽度、深浅主题和潮位图视觉。

## Implementation Changes

- 删除左栏背景矩形及不再使用的 `panel` 主题色字段；柱状轨道和筛选胶囊继续使用
  `panel_alt`。
- 三栏采用统一的 `y=20–200` 内容边界，两条分隔线同步延伸到该边界。
- 左栏品牌、中栏 `DAILY TIDE`、右栏 `TOOL MIX` 统一到 `y=38` 标题基线。
- 移除副标题后，将图表顶部上移到 `y=56`，右栏工具行同步上移；左栏底部指标、
  中栏日期、右栏筛选胶囊统一落在约 `y=194–199` 的底部边界。
- 相应调整潮位图高度、空数据提示和工具行坐标，不改变数据计算、颜色、比例或筛选内容。

## Interfaces

- 不修改 `GET /token-usage/card.svg` 的参数、响应头、SVG 尺寸或数据来源。
- 不修改 Token 汇总逻辑、K/M/B 格式化、README 嵌入方式和前端页面。

## Test Plan

- 更新 SVG renderer 测试，断言左栏独立背景矩形和两处副标题均不存在。
- 断言三栏标题基线、分隔线范围及底部元素位置符合统一边界。
- 回归深浅主题、空数据、7/30 天、单工具与全部工具、趋势图、百分比及安全约束。
- 执行 `git diff --check`；本机不运行 Python，相关 pytest 由用户执行。

## Assumptions

- “高度统一”指三栏共享顶部标题基线和底部内容边界，不改变三栏宽度。
- 卡片外层背景、圆角和边框保持不变，不为三栏新增等高容器轮廓。
