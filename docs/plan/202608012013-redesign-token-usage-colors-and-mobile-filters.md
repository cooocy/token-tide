# 重设计 Token 用量图表配色与移动端筛选

## Summary

- 模型饼图改用独立的高明度多色相色系，与工具饼图的既有色值分开，并强化模型之间的辨识度。
- 手机端工具筛选改为单行横向滑动胶囊，避免五个选项自然折行，并保持 44px 触控高度。

## Implementation Changes

- 保留工具配色不变；模型前五名依次使用紫晶 `#C4A7FF`、青柠 `#B8E45C`、琥珀 `#FFD166`、冰蓝 `#4CC9F0`、珊瑚红 `#FF6B6B`，“其他”使用中性石板色 `#65757C`。饼图与图例继续共享同一颜色数据。
- 为工具筛选增加独立样式标识。小于等于 420px 时取消网格布局，改为不换行、可横向滚动且带滚动吸附的胶囊轨道；隐藏视觉滚动条，但保留触摸、触控板和键盘滚动能力。
- 手机端保留“工具”标签与现有按钮文案；按钮不压缩，`全部 / Claude / Codex / OpenCode / Pi` 均保持完整显示。首次打开带 `tool` 参数的 URL 或切换选项后，将当前选中项滚动到可视区域。
- Token 用量页定义统一的 `20px` 卡片圆角，并应用于概览、加载骨架、筛选面板、区间读数和分析内容卡；胶囊按钮与圆形图表保留各自的形状语义。
- 时间筛选、桌面布局、URL 参数、Summary 请求、图表数据口径及 `UsageDistributionChart` 公共接口保持不变；不修改后端、API、类型或数据库。

## Test Plan

- 静态检查模型前五名、超过五个模型的“其他”、空数据及单模型场景，确认饼图和图例颜色一致且不再复用工具色板。
- 用户在 320px、375px、390px 和 420px 宽度下确认工具项始终单行、可以顺畅横滑、选中态可见，并且不会引起页面整体横向滚动。
- 检查 `?tool=pi`、`?tool=opencode` 等直接访问场景能够显示对应选中项；键盘焦点、`aria-pressed` 和 44px 触控区域保持有效。
- Agent 仅执行源码检查与 `git diff --check`；不运行前端构建、类型检查、lint、测试或开发服务器，由用户完成运行和视觉验证。

## Assumptions

- 多色相色板按模型用量排名分配，而不是按模型名称固定绑定；排名变化时颜色可随之变化。
- 横向滑动仅用于手机端工具筛选，桌面端继续完整展示全部选项。
- 本次不调整页面其他卡片、模型排行条形图、文案或数据逻辑。
