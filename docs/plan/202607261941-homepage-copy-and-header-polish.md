# 首页文案与标题栏精简

## Summary

统一首页表达，减少“潮位”类意象文案，并精简 logo、状态和余额标题区域。

## Implementation Changes

- 首页副标题由“AI 账户余额潮位”改为“多平台余额监控”。
- logo 仅移除主页标题左侧容器的边框和背景，保留图标尺寸、位置及平台卡片图标样式。
- 右上角状态由“n / m 正常”改为“n / m”，保留绿色状态点；通过无障碍标签保留“正常平台数/平台总数”的完整含义。
- 主区眉题由“CURRENT TIDE”改为“BALANCE DASHBOARD”，大标题继续使用“平台余额”。
- 删除主区标题下方的更新时间整行；平台卡片各自的更新时间继续保留。
- 同步删除首页不再需要的最近更新时间汇总计算，并清理原更新时间样式，避免其选择器误作用于英文眉题。
- 不修改后端接口、数据结构、公共格式化函数或历史详情页。

## Verification

- 静态检查首页组件和样式差异，确认旧文案及主区更新时间节点已移除。
- 检查有数据、加载中、空数据和请求失败状态下的标题区布局。
- 检查窄屏下 logo、品牌文字与右侧“n / m”不发生拥挤或换行。
- 按项目约定不执行 `pnpm`、Vite、TypeScript、lint 或构建命令；运行和视觉验收由用户完成。

## Assumptions

- “去掉圆形外框”包括移除边框和半透明圆形背景，但不修改 `favicon.svg` 图案本身。
- “刚刚更新标记去掉”仅指主页大标题下方的汇总更新时间，不影响平台卡片中的更新时间。
