# TokenTide 移动端潮汐仪表盘设计

## Summary

- 重新设计余额总览与平台历史两页，以手机单手操作为第一优先，同时兼容桌面宽屏。
- 采用克制的“潮汐仪表”视觉：深海底色、清晰大金额、连续潮位轨迹；不使用常见的数据大屏渐变。
- 不修改后端接口，不新增组件库、图表库或字体依赖。

## Visual System

- 色板：深渊 `#071820`、海床 `#0C2731`、浪沫 `#E7F5F4`、薄雾 `#A8CFCB`、洋流 `#32D6C5`、告警 `#FF796F`。
- 字体：标题与金额使用 `Avenir Next / ui-rounded`，中文正文使用系统字体，时间与币种使用 `SFMono-Regular / ui-monospace`。
- 标志性元素是一条连接平台状态点的“潮位轨迹”；进入历史页后，它转化为真实余额折线。其余区域保持平面、无渐变、少阴影。
- 所有触控目标至少 `44px`；适配刘海与底部安全区；尊重 `prefers-reduced-motion`。

## Implementation Changes

- 总览页改为移动端纵向平台卡片：展示规范化平台名、状态、各币种余额、最近成功时间和历史入口；不跨币种汇总金额。
- 根据 `SUCCESS / RUNNING / FAILED / NEVER_REFRESHED` 呈现明确中文状态。失败时保留并展示上次成功余额，同时提供可展开的错误信息。
- 页面底部增加安全区适配的粘性刷新操作；刷新期间禁用重复操作并保留当前数据，完成后给出成功或部分失败反馈。
- 历史页使用原生响应式 SVG 绘制单币种折线，包含首末值、最低/最高位、触摸定位点；多币种时提供币种切换，并以 `?currency=` 保存当前选择。
- 图表下方保留移动端记录列表作为精确数据和无障碍替代；桌面端扩展为图表与记录双栏，不恢复横向滚动表格。
- 抽取金额、相对时间、平台名称、图表坐标等纯函数；统一 loading 骨架、空状态、错误重试和键盘焦点样式。
- 主要修改集中在两页组件和 `frontend/src/styles/global.css`，必要时新增轻量展示组件与格式化工具。

## Test Plan

- 验证四种平台状态、无平台、无快照、单币种、多币种、负数及超长金额。
- 验证首次加载失败、全量刷新部分失败、单平台刷新失败时旧数据不会消失。
- 验证 320px 手机、常见刘海屏、720px 分界和桌面宽屏布局，无横向溢出。
- 验证 SVG 在单点、等值、负值及 100 条记录下仍能正确绘制和触摸定位。
- 验证键盘焦点、屏幕阅读器标签、颜色对比和减少动态效果。
- 遵循仓库规则，不运行 `build`、`dev`、`preview`、`vite`、`tsc` 或 `lint`；完成后由用户执行前端检查。

## Assumptions

- 固定使用深色潮汐主题，本轮不增加浅色主题切换。
- 继续使用现有 API 和路由；历史查询默认沿用最近 100 条数据，币种切换通过现有 `currency` 参数重新加载。
- 动效仅用于状态点和图表出现过程，不实现下拉刷新或持续波浪动画。
