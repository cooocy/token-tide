# 补充累计 Token 卡片信息

## Summary

- 利用累计总用量卡片右侧留白，展示同一全历史口径下的 Token 明细。
- 保持总 Token 与请求次数为主读数，输入、输出为主要明细，缓存写入、缓存读取、推理为次要明细。
- 不新增接口，不改变 `total_tokens` 独立统计的语义。

## Implementation

- 在累计卡片中加入“累计明细”定义列表，直接读取 overview totals 已有的 5 个 Token 字段。
- 手机常见宽度采用左右布局；极窄屏和桌面三栏中的窄卡片采用上下布局，避免压缩主读数。
- 延续现有深海色板、展示字体和数据字体，以分隔线和字号层级编码主次，不增加无含义装饰。

## Verification

- 静态检查字段、可访问标签、极大数字截断与响应式规则。
- 执行 `git diff --check`。
- 不运行前端构建、类型检查、lint 或开发服务器；视觉与编译验证由用户执行。
