# 稳定 Token Usage 模型颜色

## 问题

模型饼图当前按每张卡片内的用量排名依次分配颜色。今日与总计的模型排名不同时，同一模型会显示成不同颜色；工具颜色则已经按工具标识固定。

## 方案

1. 保留工具的固定颜色、模型的多色视觉体系、Top 5 与“其他”聚合规则。
2. 将模型颜色改为根据规范化模型名进行确定性映射，不再依赖当前数据集里的排名。
3. 让今日、总计及后续复用 `modelDistribution` 的视图共享同一映射逻辑，饼图与图例继续读取同一个颜色值。
4. 仅做静态检查，不执行前端构建、类型检查、Lint 或运行命令。

## 视觉约束

- 模型色继续使用与工具色独立的多色调色盘，不改变现有信息层级、排版和交互。
- “其他”继续使用固定中性色，避免被误认为某个具体模型。
- 同一模型名在所有时间范围内必须得到同一颜色。

## 验证

- 检查模型颜色函数不依赖数组索引或用量排名。
- 检查今日与总计均通过同一个 `modelDistribution` 路径生成饼图和图例。
- 执行 `git diff --check` 并人工检查限定范围内的 diff。
