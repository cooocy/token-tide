# 今日视图替换模型用量卡片

## Summary

- 移除「今日」中的 `MODEL SHARE / 按模型` 圆环卡片。
- 增加与「用量分析」完全一致的 `MODEL USAGE / 模型用量` 列表。
- 保持「Tokens 分布」「按工具」「模型用量」位于同一个外层大卡片中，以分隔线区分内部区域。

## Implementation Changes

- 抽取可复用的模型用量列表组件，由「今日」和「用量分析」共同使用，统一标题、模型数量、Token 数、相对用量条、请求次数和占比。
- 「今日」使用 `todaySummary.models` 和今日总 Token 计算模型列表；删除今日模型圆环数据、非零模型计数及对应渲染。
- 调整今日大卡片内的模型列表样式：保留「用量分析」的内容、间距和滚动规则，但去除独立卡片边框与圆角，使三个区域继续共享一个外框。
- 保持桌面三列、移动端纵向排列；不修改「总计」的按模型圆环卡片。
- 不修改后端、API、URL、数据口径、加载重试逻辑或现有模型排序。

## Interfaces

- 不新增或修改公共 API、响应结构或路由。
- 仅增加页面内部复用组件及布局样式。

## Test Plan

- 静态检查今日不再出现「按模型」，并显示完整「模型用量」列表。
- 验证模型用量的数值、进度条、请求次数和占比均基于今日数据。
- 验证三部分只有一个外层圆角边框，内部无嵌套卡片边框。
- 覆盖零模型、单模型、多模型、长模型名和大 Token 数。
- 检查桌面三列及 320–420px 移动端纵向布局，无横向溢出。
- Agent 仅执行源码检查和 `git diff --check`；构建、类型检查、Lint 和运行验证由用户执行。

## Assumptions

- 「样式全部照搬」包括「用量分析」现有的全部模型列表，而非 Top 5 或「其他」聚合。
- 「今日」现有「Tokens 分布」与「按工具」的文案和视觉保持不变。
- 模型列表过长时沿用现有规则：桌面限制高度并滚动，移动端自然展开。
